# Система цифрового підпису зображень з використанням RSA та LSB-стеганографії

Це індивідуальне завдання реалізує захищену систему підпису зображень із використанням алгоритму RSA та стеганографічного вбудовування підпису (LSB). Метою є забезпечення цілісності та автентичності зображення без візуальних змін.

## Призначення

Цей набір скриптів дозволяє:
1.	Згенерувати пару RSA ключів.
2.	Створити цифровий підпис для зображення.
3.	Сховати підпис у зображенні за допомогою LSB-стеганографії.
4.	Перевірити автентичність зображення та його підпису.

## Принцип роботи


### 1. Генерація ключів (`generate_keys.py`)
У цьому кроці створюється криптографічно стійка пара RSA-ключів за допомогою бібліотеки cryptography.
Алгоритм RSA (Rivest–Shamir–Adleman) — один із найпоширеніших алгоритмів з відкритим ключем для цифрового підпису та шифрування.

У результаті отримуємо таку пару RSA ключів (4096 біт):
- private.pem — приватний ключ для створення підпису.
- public.pem — публічний ключ для перевірки підпису.

Обидва ключі зберігаються в директорії keys/ у форматі PEM.

### 2. Підпис зображення (`sign_image.py`)
Скрипт реалізує процес цифрового підпису зображення та приховування підпису з використанням LSB-стеганографії.

Як це працює:
1.	Зчитування зображення у бінарному форматі.
2.	Гешування вмісту зображення через SHA-256 — це створює унікальний цифровий відбиток (хеш) зображення.
3.	Підпис хешу приватним RSA-ключем — на основі відкритого алгоритму шифрування, що гарантує авторство.
4.	Кодування підпису у hex-формат — щоб його можна було вставити у вигляді тексту.
5.	Вбудовування підпису у зображення з використанням стеганографії LSB:
- найменш значущі біти (least significant bits) кожного пікселя замінюються бітами цифрового підпису;
- це не впливає на зовнішній вигляд зображення, бо зміни настільки малі, що не помітні людському оку;
- при цьому підпис не зберігається відкрито в метаданих або як текст у файлі, тому випадково витягти або помітити його складно без знання методу.
6.	Збереження результату — як окремого зображення (example_signed_melon.png), яке виглядає як оригінал, але містить у собі криптографічно безпечний підпис.

### 3. Перевірка підпису (`verify_signature.py`)
Цей скрипт:
1.	Зчитує оригінальне зображення та підписане зображення.
2.	Витягує схований у зображенні hex-підпис через stegano.lsb.
3.	Повторно обчислює SHA-256 геш оригінального зображення.
4.	За допомогою публічного ключа перевіряє, чи підпис відповідає цьому гешу.

## Інструкція з використання
### Крок 1: Встановлення бібліотек
Перед початком роботи переконайтесь, що у вас встановлено Python 3.7+ та pip.

Встановіть необхідні бібліотеки, що використовуються для:
- створення та перевірки цифрових підписів (cryptography);
- приховування інформації в зображенні (stegano);
- обробки зображень (Pillow).

Виконайте:
```bash
pip install -r requirements.txt
```
### Крок 2: Генерація ключів
RSA ключі можна згенерувати програмно. Для цього:

**Перейдіть до папки keys/ з основної директорії проєкту:**
```bash
cd keys
```
**Після цього виконайте наступну команду:**
```bash
python generate_keys.py
```
В результаті буде створено:
- private.pem — приватний ключ, що використовується для створення підпису
- public.pem — публічний ключ, що використовується для перевірки підпису

**Примітка:** У цьому репозиторії вже міститься пара прикладових ключів у папці keys/. Якщо вони вже існують, ви можете не генерувати їх повторно. Але за потреби — можливо створити нову пару власноруч.

### Крок 3: Підпис зображення
Після генерації ключів ви можете створити цифровий підпис і вбудувати його у зображення, не змінюючи його візуального вигляду.
Запустіть скрипт однією з наступних команд (залежно від вашої системи та налаштувань Python):
```bash
python sign_image.py
```
або
```bash
python3 sign_image.py
```
У файлі sign_image.py за замовчуванням встановлені такі шляхи:
```python
sign_image(
        image_path="test_photos/melon.png",
        private_key_path="keys/private.pem",
        output_path="test_photos/example_signed_melon.png",
    )
```
В результаті буде створено файл example_signed_melon.png — це зображення, в яке вбудовано підпис за допомогою LSB-стеганографії.
Воно відкривається як звичайне зображення, але містить невидимий підпис.
Після **успішного** виконання ви отримаєте повідомлення:
```
Image successfully signed and saved to: test_photos/example_signed_melon.png
```

### Крок 4: Перевірка зображення
Цей крок дозволяє переконатись, що зображення не було змінено та дійсно було підписане власником приватного ключа.
Запустіть скрипт однією з наступних команд (залежно від вашої системи та налаштувань Python):
```bash
python verify_signature.py
```
або
```bash
python3 verify_signature.py
```
Перевірка виконується для підписаного зображення `example_signed_melon.jpg` з використанням відкритого ключа з `keys/public.pem`.

У файлі verify_signature.py за замовчуванням встановлено такі шляхи:
```python
verify_image(
    image_path="test_photos/example_signed_melon.png",
    original_image_path="test_photos/melon.png",
    public_key_path="keys/public.pem"
)
```
Якщо підпис дійсний і зображення не було змінене — буде виведено повідомлення:
```
Signature is valid. Image is authentic.
```
Якщо зображення було змінене або файл не містить підпису — зʼявиться відповідне попередження:
```
Signature is invalid or the image has been modified.
```
Якщо зображення не міститиме підпису:
```
Signature not found in the image.
```
