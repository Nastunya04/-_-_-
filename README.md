# Система цифрового підпису зображень за допомогою RSA\

Це індивідуальне завдання реалізує захищену систему підпису зображень із використанням **цифрового підпису RSA**. Мета — надати спосіб підтвердження автентичності та цілісності зображення без зміни його зовнішнього вигляду.

## Призначення

Цей скрипт:
1. Створює **цифровий підпис** для вхідного зображення.
2. **Вбудовує підпис** у кінець файлу без порушення формату.
3. Дозволяє **перевірити автентичність** зображення через відкритий ключ.
---
## Принцип роботи

### 1. Генерація ключів RSA
Пари ключів (приватний/публічний) генеруються за допомогою `OpenSSL`:

```bash
openssl genpkey -algorithm RSA -out private.pem -pkeyopt rsa_keygen_bits:4096
openssl rsa -pubout -in private.pem -out public.pem
```
В результаті отримуємо:
- `private.pem` — приватний ключ, що використовується для створення підпису (зберігається в `keys/`)
- `public.pem` — публічний ключ, що використовується для перевірки підпису

**Примітка:** У цьому репозиторії вже міститься пара прикладових ключів у папці keys/. Якщо хочете — можете згенерувати власні ключі заново.

### 2. Підпис зображення (`sign_image.py`)
Скрипт читає зображення (у форматі JPG/PNG/BMP), обчислює його SHA-256 хеш та створює цифровий підпис на основі приватного ключа. Підпис кодується в Base64 і додається в кінець зображення після спеціального роздільника <<<SIGNATURE>>>. Такий підхід дозволяє зберегти цілісність перегляду зображення стандартними засобами Windows/macOS.

### 3. Перевірка підпису (`verify_signature.py`)
Цей скрипт:
1. Відкриває підписане зображення.
2. Відокремлює підпис за роздільником.
3. Обчислює SHA-256 хеш зображення.
4. Перевіряє підпис, використовуючи публічний ключ.

Якщо зображення не було змінено, буде виведено повідомлення про успішну валідацію. Якщо зображення змінено або підпис некоректний — буде виведено повідомлення про невідповідність.

## Інструкція з використання
### Крок 1: Встановити бібліотеки
Перед початком роботи потрібно встановити всі необхідні залежності, зокрема бібліотеку cryptography, яка використовується для створення та перевірки цифрового підпису.

Переконайтесь, що у вас встановлено pip, після чого встановіть потрібні бібліотеки:
```bash
pip install -r requirements.txt
```
### Крок 2: Генерація ключів
На цьому етапі створюється пара:
- приватний ключ (private.pem) — використовується для створення підпису,
- публічний ключ (public.pem) — використовується для перевірки підпису.
```bash
openssl genpkey -algorithm RSA -out private.pem -pkeyopt rsa_keygen_bits:4096
openssl rsa -pubout -in private.pem -out public.pem
```
Якщо файли `keys/private.pem` та `keys/public.pem` вже є — повторно генерувати не потрібно.
### Крок 3: Підпис зображення
Цей крок створює цифровий підпис для зображення та додає його в кінець файлу, не змінюючи спосіб його відображення.
Запустіть скрипт:
```bash
python3 sign_image.py
```
У файлі sign_image.py за замовчуванням встановлені такі шляхи:
```python
sign_image(
    image_path="test_photos/melon.jpg",
    private_key_path="keys/private.pem",
    output_path="test_photos/example_signed_melon.jpg"
)
```
Результатом буде створене зображення example_signed_melon.jpg, яке містить підпис, але відкривається як звичайне зображення.
### Крок 4: Перевірка зображення
Цей крок дозволяє переконатись, що зображення не було змінено та дійсно було підписане власником приватного ключа.
```bash
python3 verify_signature.py
```
Перевірка виконується для підписаного зображення `example_signed_melon.jpg` з використанням відкритого ключа з `keys/public.pem`.

У файлі verify_signature.py за замовчуванням встановлено:
```python
verify_image_signature(
    image_path="test_photos/example_signed_melon.jpg",
    public_key_path="keys/public.pem"
)
```
Якщо підпис дійсний і зображення не було змінене — буде виведено повідомлення:
```
Signature is valid. The image is authentic.
```
Якщо зображення було змінене або файл не містить підпису — зʼявиться відповідне попередження.
